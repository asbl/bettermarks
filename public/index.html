Note 1: alle Übungen mit 100 %. Note 5: unterhalb der aktiven Grenzen. Note 6: keine Bearbeitung oder ausschließlich 0 %. Die Notenbasis ändert die Symbole nicht.

Aktivitäten für Gesamt auswählen

Positionen von links: 1-4 = erste vier, 2-5 = zweite bis fünfte, 1, 3-5 = einzelne und Bereiche. Nur angehakte Aktivitäten zählen für Gesamt; alle Spalten bleiben sichtbar.

Klick auf eine Bewertung zeigt die Einzelergebnisse. Aktivitäten bleiben in Export-Reihenfolge.

Berechnung

Einzelne Ergebniszellen mit 0 % zählen als bearbeitet, wenn im selben Thema mindestens ein Ergebnis über 0 % vorliegt. Besteht ein Thema nur aus 0 % und leeren Zellen, zählt es als nicht bearbeitet. „+“ setzt voraus, dass jede einzelne Übung über 0 % erreicht. Bei gemischten 0-%-Ergebnissen ist höchstens „~“ möglich. Genau die Hälfte bearbeitet erhält das Symbol „-“. Die Notengrenzen gelten unabhängig davon.

Gesamt ist der Durchschnitt der Themennoten, angezeigt mit zwei Nachkommastellen. Bei der Erfolgsquote ist die Grundlage der Durchschnitt aller Übungsergebnisse; leere Übungen zählen als 0 %. Standardmäßig zählen alle Themen gleich, unbearbeitete Themen als 6.
